Privacy Policy

ImgCollector – Image Downloader & Batch Download

This Privacy Policy explains how ImgCollector handles information when you use the Chrome extension. ImgCollector helps users find image URLs on the current webpage, preview and filter images, and download selected images in batches.

1. Information Processed

When you activate ImgCollector on a webpage, the extension examines image-related information available on that page, including image URLs from image elements, source elements, and CSS background images. It identifies image formats when possible and displays image previews and URLs so you can select files to download. A URL may contain information included by the website that supplied it.

2. Local Storage

ImgCollector's current functionality keeps the scanned image list, filter input, and selection state temporarily within the extension popup. It does not use Chrome extension storage to maintain a persistent browsing history or image collection. Files you choose to download are saved through Chrome's download functionality according to your browser settings.

3. Data Collection and Transmission

ImgCollector does not require an account and is not designed to send image lists, browsing history, or personal information to developer-operated servers. Image previews and user-requested downloads may cause Chrome to request image files from the websites or image hosts that provide them. Those requests are subject to the relevant websites' practices and your browser settings.

4. Browsing History

ImgCollector accesses the active webpage only when you invoke the extension to find images. It does not compile or transmit a browsing history to the developer.

5. Analytics, Advertising, and Sale of Data

  • The current extension does not include analytics or user-behavior tracking.
  • The current extension does not include advertising functionality.
  • The developer does not sell user information or share it for advertising purposes through the extension.

6. Browser Permissions

ImgCollector uses the following Chrome permissions to perform its functions:

  • activeTab: Allows temporary access to the webpage you are viewing when you activate the extension.
  • scripting: Allows ImgCollector to run its image-discovery script on the active webpage.
  • downloads: Allows Chrome to download the images you select.

These permissions are used for user-initiated image discovery and downloading, not for monitoring unrelated tabs or collecting browsing activity.

7. User Control

You choose when to open ImgCollector, which images to select, and when to start downloads. You can deselect images, close the popup, manage downloaded files using Chrome, or uninstall the extension at any time.

8. Security Considerations

Images and image URLs may contain sensitive or copyrighted material. Review selected files and respect website terms and applicable rights before downloading or sharing them. Some images may fail to preview or download because of website restrictions, authentication requirements, or browser security protections. ImgCollector does not remove these protections.

9. Changes to This Policy

This policy may be updated when ImgCollector's functionality or data-handling practices change. The latest version will be made available on the extension's published privacy policy page.

10. Contact

For privacy-related questions, please contact the developer using the support contact information published on the ImgCollector Chrome Web Store listing.
